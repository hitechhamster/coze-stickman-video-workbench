# Coze Stickman Video Workbench

**彩色火柴人短视频本地工作台：按 Coze 工作流生成素材，直接输出可编辑的剪映草稿。**

基于 [hitechhamster/ai-video-workbench](https://github.com/hitechhamster/ai-video-workbench) 改造，将「彩色火柴人中文横屏」Coze 工作流迁移到本地。使用网页界面输入文案或选题，逐段生成配音、按原规则合并分镜、生成水彩火柴人插画，然后加入字幕、音乐与特效并写入剪映。

## 制作流程

```text
选题 / 自定义文案
  → 原提示词口播文案
  → 文案分段与逐段配音
  → 实测微秒时间线
  → 前四段独立、后续三到五段合镜
  → 彩色水彩火柴人配图
  → 字幕 + 音乐 + 点击音效 + 震动 + 荧幕噪点
  → 本地剪映草稿 → 剪映编辑 / 导出
```

## 原工作流默认配方

| 项目 | 参数 |
|---|---|
| 画布 | 1920 × 1080 横屏 |
| 画风 | 水彩火柴人，保留原系统提示词、角色附加词与负向词 |
| 分镜 | 前 4 段独立，后续 3–5 段合并；末尾均衡分组 |
| 配音 | 逐段生成，1.1 倍速，人声增强3 |
| 字幕 | 高字标志圆，字号5、缩放1.5，白字黑边 |
| 背景音乐 | 原素材循环平铺，音量0.3 |
| 点击音效 | 开头0–391833微秒，音量3 |
| 全局特效 | 震动、荧幕噪点 |
| 转场 / 推拉 | 原文件未指定，直接切镜 |

## Windows 快速开始

1. 下载仓库 ZIP 并解压，安装 **Python 3.10+**（勾选添加到 PATH）。
2. 双击 **安装.bat** 安装依赖。仓库包含已构建界面，普通运行不需要安装 Node.js。
3. 双击 **启动.bat**，浏览器打开 `http://127.0.0.1:8010/ui/`。
4. 在「服务配置」填写模型服务密钥、模型 ID 和音色 ID。
5. 将剪映「全局设置 → 草稿位置」中的路径填入工作台。
6. 输入文案或选题，点击「生成剪映草稿」。完成后在剪映草稿箱中编辑和导出。

关闭后台服务：运行 **停止.bat**。

## 支持的模型服务

- 文案 / 提示词：豆包火山方舟、Gemini、OpenRouter。
- 配图：豆包 Seedream、Gemini、OpenRouter。
- 配音：豆包语音、Gemini、MiniMax。

服务可分别选择。默认生图模型是 `doubao-seedream-4-5-251128`。密钥保存在本机 `backend/.env`，接口不会回显密钥，生成费用由对应服务账户承担。模型能否调用以当前厂商和账户为准。

Coze 的数字音色 ID 无法直接调用厂商 API，需填写相应厂商音色 ID。要接近原片，应使用对应的模型与音色。

## 已验证与边界

- 10 项后端测试通过，分镜规则覆盖1–100段输入；前端类型检查和生产构建通过。
- 测试音频和图片跑通真实草稿组装，验证字幕、配音、音量、点击时长和特效轨道。
- 第8段空配音会明确报错。重试复用已有素材，不丢句、不跳段。
- 原工作流50个节点均有[实现对照](工作流节点对照.json)。

原导出中名为“正文视频”的分支实际仅调用图像生成，没有视频生成模型；本地输出为图片分镜，不产生角色动作动画。两个原草稿链路引用同一批正文素材，本地只写最终一套。

封闭插件的源码没有导出，文案切分、去静音和提示词优化使用本地替代。字幕原Y坐标-800暂换算为-0.8，需在剪映校准。真实模型生成与当前剪映版本的视觉效果尚待验证，不能保证完全一致。

详细使用方式及移植边界见 [改造说明](改造说明.md)。发布版去除了源工作流URL中的临时访问签名；音乐和音效通过本地缓存使用。

## 开发

后端：FastAPI、SQLAlchemy、httpx、Pillow、FFmpeg、pyJianYingDraft。前端：React、TypeScript、Vite。

```powershell
# 后端测试（仓库根目录）
cd backend
..\.venv\Scripts\python.exe -m unittest discover -s tests -v

# 重新构建前端（需要 Node.js 22.12+ 和 npm）
cd ..\frontend
npm install
npm run build
```

新版工作台在 `/ui/`；上游自由工作台保留在 `/ui/classic`。
